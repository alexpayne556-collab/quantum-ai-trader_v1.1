## RESEARCH NOTE

This document provides a high-level framework for systematic opportunity identification. Key concepts demonstrated:

**1. Trend Identification:**
- Supply constraints (production can't meet demand)
- Regulatory tailwinds (government spending)
- Adoption curves (technology penetration accelerating)
- Geopolitical shifts (reshoring, trade restrictions)

**2. Company Selection:**
- Lowest cost producer wins (highest leverage to price moves)
- Capacity constraints = pricing power
- Small/mid-cap better than mega-cap (bigger moves possible)
- Rank competitors systematically (not random selection)

**3. Validation Process:**
- Verify data yourself (don't trust headlines)
- Calculate leverage mathematically (not gut feel)
- Wait for external confirmation (2+ signals)
- Execute mechanically (no emotion)

**4. Risk Management:**
- Stop losses non-negotiable
- Profit-taking at defined levels (30%, 50%, 100%)
- Position sizing (never all-in)
- Thesis monitoring (broken = exit immediately)

This is NOT a system to build today. This is a research framework to EVALUATE tomorrow. Questions to ask:
- Does this approach work for 2026 market structure?
- How do we adapt this to sector rotation (what's coming next)?
- Can this be automated to learn and evolve?
- What data sources do we trust for 2025-2026 forward?
- How do we build something that knows "what worked yesterday won't work tomorrow"?

Tomorrow's work: Analyze whether this framework applies to building an adaptive system, or if we need entirely different approaches for 2026 market dynamics.

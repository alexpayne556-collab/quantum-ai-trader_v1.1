### DOCUMENT 2: 4-Week Validation Checklist (⭐ CRITICAL FOR DOING IT RIGHT)
**File:** PERPLEXITY_TRADING_EDGE_VALIDATION_CHECKLIST.md

**Why This Matters:**
> No "peeking through the window at results like Sonnet 3.5" - this is how to validate properly

**The 4-Week Framework:**
- **Week 1:** Define edge precisely, get Claude to write backtest code
- **Week 2:** Test on 2025 data ONLY (not historical), market structure check
- **Week 3:** Add realistic costs (0.8% round trip), risk analysis
- **Week 4:** Paper trade live, compare to backtest

**Pass/Fail Criteria (USE THESE):**
| Metric | Pass | Fail |
|--------|------|------|
| Win Rate | 55-70% | <55% or >70% (overfitting) |
| Profit Factor | >1.5 | <1.5 |
| Sample Size | 100+ trades | <100 |
| Expected Value | >0.1% per trade after costs | <0.1% |
| Max Drawdown | <15% | >15% |

**Realistic Costs (IMPORTANT):**
```
Bid-ask spread: 0.2%
Execution slippage: 0.2%
Commission: 0% (Robinhood)
Total round trip: ~0.4-0.8%

A "65% win rate" with 2% average win becomes:
- Before costs: 0.65 × 2% = 1.3% expected
- After costs: 1.3% - 0.8% = 0.5% expected
- If your average win is <1%, you might be NEGATIVE after costs
```

**Verdict:** ⭐⭐⭐⭐⭐ Use this BEFORE building anything. Test any strategy this way.
